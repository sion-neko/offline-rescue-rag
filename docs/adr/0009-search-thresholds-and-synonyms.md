# 0009 「資料にない」の判定と、言い換えの辞書

- 状態：採用
- 日付：2026-11-17

## 背景
- 関係ない質問（カレーの作り方）にも、何かしらの資料が「いちばん近い」として出てしまう
- 焦っている人の言葉（圏外・たすけて・みちにまよった・ふるえる）では、点数が低く出て資料に届かなかった

## 決定
- 言い換えの辞書（`data/synonyms.json`）で、質問に含まれる言葉に応じて検索用の言葉を足す
- いちばん近い資料の点数で 3 段階に分ける（`src/rag/config.json`）
  - 0.45 未満：「資料に見つかりませんでした」。状況ボタンと 110 番を出す
  - 0.45〜0.58：結果は出すが「関係が薄いかもしれません」と添える
  - 0.58 以上：そのまま出す
- 「助けて」「救助」「110」「SOS」などが入っていたら、結果の先頭に救助を呼ぶボタンを出す

## 結果
- 関係ある質問 35 件はすべて 0.53 以上、関係ない質問は 0.51 以下になった（`scripts/eval-threshold.mjs`）
- 0.53〜0.58 の関係ある質問（のどが渇いた など）にも「関係が薄いかも」が付く。結果は出るので、安全側に倒した
- 辞書は手で育てる必要がある
