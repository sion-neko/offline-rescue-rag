# 0012 答えは安全側の指示を先に書く

- 状態：採用
- 日付：2026-11-18

## 背景
- このアプリを使うのは、山で困って焦っている人。長い文を最後まで読むとは限らず、最初に目に入った指示で動く
- 「見晴らしのよい尾根や山頂など、高い場所に移ると電波が入ることがある。ただし道が分からない状態で無理に動かない。」のように、勧めることを先に、例外の禁止を後ろに書いた文があった
- この形だと、人が前半だけを読んで動いてしまうおそれがある。また、小さい LLM が文章にまとめるとき後ろの部分を崩しやすく、実際に「無理に動かない」が「無理に動かない**と危険**です」と逆になった（`docs/llm-comparison.md`）

## 決定
- 原本（`data/qa/*.md`）・LLM の答えのどちらも、**安全側の指示（してはいけないこと・止まること）を先に書く**
- 条件つきの禁止は、条件を先に書く
  - 前：「高い場所に移ると電波が入ることがある。ただし道が分からない状態で無理に動かない。」
  - 後：「道が分からないときは、無理に動かない。道が分かっていれば、尾根や山頂など見晴らしのよい高い場所に移ると電波が入ることがある。」
- 例外は、勧めることと**同じ行に残す**
- 1 つの答えの中でも、行の順番は安全側を先にする（止まる → 落ち着く → 次の行動）

## 検討した案
- 1 行に 1 つの決まりにして、「ただし」の例外を別の行に分ける：本人が「拾われなくなるのでは」と指摘した。検索や AI の選び出しで、勧めることの行だけが拾われ、例外が落ちるおそれがある

## 結果
- 原本を QA に移すとき（0013）に、この順番に直した
- LLM のプロンプトにも、安全側の指示を先に書くよう入れる（まだ）
