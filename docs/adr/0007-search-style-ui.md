# 0007 画面はチャットではなく「検索型」にする

- 状態：採用
- 日付：2026-11-16

## 背景
- 中身は「1 問ずつ資料を検索して答える」で、前の会話を踏まえた返事はできない
- チャットの見た目（右に自分・左に AI）は分かりやすいが、「会話を続けられる」と思われてしまう
- 遭難中は手がかじかみ、電池も気になる。文字を打つのがつらい

## 決定
- Google 検索の「AI による概要」、NotebookLM の出典、赤十字の応急手当アプリを参考にした「検索型」にする
  - 入口は検索欄と「いまの状況」ボタン（タップで聞ける）
  - 結果は質問ごとのページで、吹き出しも下に固定された入力欄もない
  - 深掘りは、マニュアルの別の項目を原文で開く（0008）
- どの画面からも、右上の赤い電話ボタンで救助を呼ぶ画面へ 2 タップ以内で行ける

## 検討した案
- チャット型、状況ボタン中心の案（第 1・2 案）：本人が「正直全部微妙」とした
- Slack のスレッド型（AI の返事には返信できない）：Slack ではスレッドは返信が続くものなので、返信できないと戸惑う
- LINE bot 型：本人が LINE を好まない

## 結果
- 「続けて質問できる」という誤解は起きにくい
- 続けて聞きたい人は、検索し直すか、関連する資料を開く
