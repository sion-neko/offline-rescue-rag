# 0010 救助を呼ぶ画面と、わたしの情報

- 状態：採用
- 日付：2026-11-16、2026-11-17

## 背景
- 県警の山岳遭難の案内では、通報で伝えるのは「場所（座標）」「何があったか・けが」「氏名・年齢・持病」「電池残量」など
- 指令員が最初に聞くのは場所と何が起きたか。テストでは「何から言えばいいか分からない」という声が出た

## 決定
- 110 と 119 の大きなボタンの下に、「電話で言うこと（この順に）」を番号つきで並べる：①いる場所 ②何があったか ③人数 ④名前・年齢・持病 ⑤持ち物 ⑥電池
  - ①に GPS の緯度経度（度と度分秒）と、登録したルートを出す
  - ④に「わたしの情報」を出す
- 家族へは、電話と、本文に現在地を入れた SMS を開くボタンを置く
- 電話がつながらないとき（iPhone 14 以降の衛星経由の緊急 SOS、SMS、歩き回らない）を同じ画面に置く
- 「わたしの情報」（名前・年齢・持病・緊急連絡先・ルート・下山予定）は、登山前に入れておく。**端末の中だけに保存し、外には送らない**

## 結果
- 位置情報の許可が要る。拒否されたら「設定を開く」と、iPhone の「コンパス」アプリでの確かめ方を出す
- web 版では発信できないので、表示だけを確かめる
