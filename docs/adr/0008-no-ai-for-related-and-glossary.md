# 0008 関連する資料・あわせて確認・用語解説は AI を通さない

- 状態：採用（「あわせて確認」は 0013 で変更）
- 日付：2026-11-16、2026-11-17

## 背景
- 最初は「関連キーワード」で検索し直す案だったが、本人が「Google なら Web 全体から出るが、このアプリは同じマニュアルを探し直すだけで微妙」と指摘した
- ベクトルの近さだけで行を選ぶと、「寒い」に熱中症の「体を冷やす」が混ざるなど、逆の内容が出た

## 決定
- **関連する資料**：マニュアルの各項目に `関連:` の行で人が指定し、題名を並べる。押すと原文が開く
- **あわせて確認**：いちばん近い項目の「関連」に入っている項目からだけ、質問に近い行を選ぶ
  - 2026-11-18 変更（0013）：2 位以下の QA の答えをそのまま出す。QA の質問と比べる検索では、2 位以下は条件が重なる質問のもう片方の条件になり、1 位から離れすぎた QA は除くため
- **用語解説**：`data/glossary.md` に人が書いた説明を、文中の用語の下線とチップから開く

## 結果
- 何が出てくるかが予測でき、逆の内容が混ざらない
- マニュアルを書き足すときは、`関連:` と用語集も手で保つ必要がある
