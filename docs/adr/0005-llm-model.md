# 0005 要点を選ぶ LLM は LFM3-1.7B

- 状態：採用（2026-11-17 に LFM2.5-1.2B-JP-202606 から変更）
- 日付：2026-11-16、2026-11-17

## 背景
- 最初は「要約は難しいタスクではない」として、日本語に特化した LFM2.5-1.2B-JP-202606（約 730MB）を選んだ
- 使ってみると、命に関わる文の意味を変えた。「ヘッドランプが**あっても**歩かない」→「**あれば**」、「距離をとる」→「距離を最小限に」、条件の「乾いた服**があれば**」を落とす
- 実際に必要だったのは「意味を 1 文字も変えない要約」で、思ったより難しいタスクだった

## 決定
- LFM3-1.7B（Q4_K_M、約 1.1GB）に替える
- 考える過程（thinking）は切る。llama.rn は `enable_thinking: false`、wllama は `chat_template_kwargs: { enable_thinking: false }`、node-llama-cpp は `budgets.thoughtTokens: 0`

## 検討した案
同じ 10 問・同じプロンプトで比べた（`scripts/eval-models.mjs`、詳しくは `docs/llm-comparison.md`）。

| モデル | サイズ | 意味が変わった・資料にない行 |
|---|---|---|
| LFM2.5-1.2B-JP-202606 | 0.73GB | 8 |
| LFM3-1.7B | 1.10GB | 0 |
| Qwen3.5-2B | 1.28GB | 4（同じ句を延々と繰り返すこともあった） |
| Qwen3.5-4B | 2.74GB | 0（条件の抜けが 1） |
| Gemma 4 E2B | 3.11GB | 判定できず（考える過程を答えとして書いた） |

- Qwen3.5-4B も間違いは 0 だったが、iPhone 14（メモリ 6GB）では embedding と合わせて約 3.1GB になり、ぎりぎり

## 結果
- アプリが約 0.4GB 大きくなる
- llama.rn 0.13.0-rc.11 の iOS 版に `lfm3` の処理が入っていることは確かめた。実機での速さ・メモリは未確認
